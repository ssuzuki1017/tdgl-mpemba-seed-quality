\section*{Relation between nucleation and transition times}

Figure~S4 shows the relation between the cluster nucleation time $t_{\rm nuc}$ and the global transition time $t_{\rm tr}$ for samples in which both times were observed. The two times are strongly correlated. This supports the interpretation that the global transition time is closely tied to the stochastic nucleation time in the first-order model.

For the main first-order data set, the combined sample contains 600 realizations. Among these, 206 realizations show an observed cluster nucleation event and 165 realizations show an observed global transition by the final observation time. The scatter plot includes the 165 realizations for which both $t_{\rm nuc}$ and $t_{\rm tr}$ were observed. The Pearson correlation between these two times is approximately 0.997, and the Spearman rank correlation is approximately 0.995. The mean delay $t_{\rm tr}-t_{\rm nuc}$ is approximately 43.5 time units.

\begin{figure}[t]
\centering
\includegraphics[width=0.75\linewidth]{figS7_tnuc_vs_ttr_scatter}
\caption{Relation between the cluster nucleation time $t_{\rm nuc}$ and the global transition time $t_{\rm tr}$ in the first-order $\phi^6$ model. Only samples for which both times were observed are shown. The dashed line indicates $t_{\rm tr}=t_{\rm nuc}$.}
\label{fig:S4-tnuc-ttr}
\end{figure}

\section*{Sample-level seed-quality analysis}

As an additional check, we examined whether initial seed variables carry sample-level information about whether a cluster nucleation event is observed within the finite observation window. For each realization in the main first-order data set, we defined a binary outcome equal to one if $t_{\rm nuc}$ was observed by the final observation time and zero otherwise. We then fitted logistic models using standardized predictors. This analysis should not be interpreted as a committor calculation: it uses only a small set of initial geometric descriptors and a finite final observation time.

Table~S1 summarizes the Akaike information criterion (AIC) values for several low-dimensional models. The model using seed compactness and radius of gyration has the lowest AIC among the tested models, but its improvement over the intercept-only model is modest, with $\Delta{\rm AIC}=1.08$. The combined model containing both seed-amount and seed-geometry variables is not preferred by AIC. Thus, the sample-level predictive evidence is modest and should be used only as a consistency check.

\begin{tabular}{lcc}
\hline
Model & Predictors & $\Delta{\rm AIC}$ \\
\hline
Seed quality & $C_{\rm comp}, R_g$ & 0.00 \\

Table~S2 shows the standardized coefficients for the model containing both seed-amount and seed-geometry variables. Seed compactness has a positive standardized coefficient, $\beta=0.25$, with an approximate two-sided $p$ value of 0.052. The coefficients of $p_{\rm seed}$, $c_{\rm seed}$, and $R_g$ are not statistically decisive in this finite data set. This result is consistent with the physical interpretation that compactness may be relevant, but it is not by itself a quantitative nucleation-rate theory and should not be read as a committor estimate.
