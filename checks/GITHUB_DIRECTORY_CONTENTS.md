# What should be in each GitHub directory?

## `manuscript/`

This folder should contain manuscript source files and bibliography files.

Recommended contents:

```text
manuscript/
  manuscript_revtex.tex
  supplemental_material.tex
  references_verified.bib
  manuscript_revtex.pdf             # optional
  supplemental_material.pdf          # optional
```

Required for reproducibility:

- `manuscript_revtex.tex`
- `supplemental_material.tex`
- `references_verified.bib`

Optional but useful:

- compiled PDFs
- previous draft versions only if clearly named, e.g. `archive/`

Avoid:

- Overleaf temporary files
- `.aux`, `.bbl`, `.blg`, `.log`, `.out`, `.synctex.gz`
- duplicate old drafts with confusing names

## `figures/`

This folder should contain the figure files used by the manuscript and, optionally, regenerated PNG versions.

Recommended contents:

```text
figures/
  phi4_baseline_transition_time.pdf
  fig2_nucleation_multipanel.pdf
  fig3_seed_amount_multipanel.pdf
  fig4_seed_quality_multipanel.pdf

  figS1_p_ordered_seed.pdf
  figS2_c_ordered_seed.pdf
  figS3_cluster_threshold_nucleation_probability.pdf
  figS4_dt_dependence_nucleation_probability.pdf
  figS5_p_seed_robustness.pdf
  figS6_seed_compactness_robustness.pdf
```

Optional:

- `.png` versions for GitHub preview
- summary CSV files if generated by the figure scripts

Avoid:

- exploratory figures not used in the paper, unless placed in `figures/archive/`
- duplicate older versions that might confuse readers

## `data/`

This folder should contain the CSV files needed to regenerate every figure.

Recommended contents:

```text
data/
  phi4_samples.csv
  phi6_*.samples.csv
  summary_*.csv       # optional
```

For the main paper, the important files are:

- `phi4_samples.csv`
- main `phi6` sample CSV for `D_f=9e-3`, `seed=5678`
- main `phi6` sample CSV for `D_f=9e-3`, `seed=9876`
- cluster-threshold check CSVs
- `dt=0.01` check CSV
- `N=128` check CSV
- `preeq_steps=1000` check CSV

Avoid:

- very large temporary output files
- incomplete failed runs unless clearly moved to `data/archive/`
- local path logs containing personal machine paths

## `src/`

This folder should contain source code used to run simulations and generate figures.

Recommended contents:

```text
src/
  tdgl_run_auto_v3.py
  tdgl_manuscript_figures_v4_multipanel.py
  tdgl_phi4_baseline_figure.py
```

Optional:

```text
src/
  tdgl_manuscript_figures_v3.py
  tdgl_mpemba_revised.py
```

If optional scripts are included, add comments or README notes explaining whether they are legacy/exploratory.

Avoid:

- notebook checkpoints
- temporary debug scripts
- scripts that require hard-coded local paths like `C:\Users\...`
