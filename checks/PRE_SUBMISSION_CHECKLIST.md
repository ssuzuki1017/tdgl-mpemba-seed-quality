## APS/PRE items to verify at submission

1. Upload main manuscript source and generated PDF.
2. Upload Supplemental Material as a separate file.
3. Upload figure files if required separately by the submission system.
4. Provide Data Availability Statement in the submission form if requested.
5. Confirm AI-tool disclosure matches APS's current AI-writing-tool guidance.
6. Confirm author affiliation and email.
7. Add ORCID if available.
8. Confirm conflict-of-interest / funding statements.
9. Confirm that the Supplemental Material is cited in the manuscript if the journal requests an explicit citation.
10. Check whether APS requests a compiled `.bbl` file in addition to `.bib` for the final source upload.

## Notes

- REVTeX 4.2 is appropriate for APS/Physical Review submissions.
- The main manuscript and supplement currently compile separately.
- The current manuscript has a Data Availability section using the conservative phrase "available from the author upon reasonable request." If a GitHub or Zenodo repository is prepared, replace this with the repository URL or DOI.
